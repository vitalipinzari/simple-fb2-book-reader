# 12 — Assets and icons: fonts, hyphenation patterns, licence texts, application icons

Scope: every non-code file the application ships or is built with — where each comes from, how it is named,
its exact checksum, and how the app uses it. Text assets that were written for Lanternleaf (the hyphenation notes
and the third-party notices) are verbatim in `ai/files/05-docs-assets-tools.md`; downloaded files are fetched
from their upstream sources; icons are generated by `tools/make_icon.py` (verbatim). After this step every asset
line of `ai/files/checksums.sha256` must match.

## 1. `assets/` (shipped with the app)

`assets/` is shared by both platforms: CMake copies it next to the exe after every build and stages it into
`release/Windows/assets/`; Gradle packages it as the APK's assets (`assets.srcDirs = ["../../assets"]`). The app
reads every asset whole into memory at start-up with `platform::loadAsset()` (so the staged folder can be
replaced while the app runs). Layout:

```
assets/fonts/PTSerif-Regular.ttf    PTSerif-Italic.ttf    PTSerif-Bold.ttf    PTSerif-BoldItalic.ttf
assets/fonts/PTSans-Regular.ttf     PTSans-Italic.ttf     PTSans-Bold.ttf     PTSans-BoldItalic.ttf
assets/fonts/OFL-PTSerif.txt        OFL-PTSans.txt
assets/hyphenation/hyph-en-us.pat.txt   hyph-en-us.hyp.txt   hyph-ru.pat.txt   hyph-ru.hyp.txt   README.md
assets/licenses/THIRD-PARTY-NOTICES.txt
```

## 2. Application icons (`tools/make_icon.py`, verbatim)

The icon is drawn procedurally with numpy (no image libraries): a rounded dark page (vertical gradient from
`(0.045, 0.035, 0.028)` at the bottom to `(0.13, 0.10, 0.075)` at the top, half-size 0.94, corner radius 0.24),
a warm amber glow (`(1.0, 0.62, 0.18)`, Gaussian, alpha 0.56), and a leaf — the lens-shaped intersection of
two circles (R 0.80, offset 0.50) rotated 45°, shaded from `(0.90, 0.42, 0.08)` to `(1.00, 0.80, 0.32)` with a
light rim, four chevron side veins, a tapering central vein and a stem in `(0.45, 0.20, 0.04)`. Each size is
rendered at 4× and box-filtered down with premultiplied alpha, then written as an 8-bit RGBA PNG (zlib level 9);
the `.ico` holds PNG-compressed entries.

Run it with any Python 3 that has numpy, for example Blender's bundled Python:

```powershell
& "<Blender 5.2>\5.2\python\bin\python.exe" -I tools\make_icon.py res android\app\src\main\res
```

## 3. One-shot setup (PowerShell)

```powershell
$fonts = "https://raw.githubusercontent.com/google/fonts/main/ofl"
$hyph  = "https://raw.githubusercontent.com/hyphenation/tex-hyphen/master/hyph-utf8/tex/generic/hyph-utf8/patterns/txt"
New-Item -ItemType Directory -Force assets\fonts, assets\hyphenation | Out-Null
foreach ($s in "Regular", "Italic", "Bold", "BoldItalic") {
  Invoke-WebRequest "$fonts/ptserif/PT_Serif-Web-$s.ttf" -OutFile "assets\fonts\PTSerif-$s.ttf"
  Invoke-WebRequest "$fonts/ptsans/PT_Sans-Web-$s.ttf"   -OutFile "assets\fonts\PTSans-$s.ttf"
}
Invoke-WebRequest "$fonts/ptserif/OFL.txt" -OutFile assets\fonts\OFL-PTSerif.txt
Invoke-WebRequest "$fonts/ptsans/OFL.txt"  -OutFile assets\fonts\OFL-PTSans.txt
foreach ($f in "hyph-en-us.pat.txt", "hyph-en-us.hyp.txt", "hyph-ru.pat.txt", "hyph-ru.hyp.txt") {
  Invoke-WebRequest "$hyph/$f" -OutFile "assets\hyphenation\$f"
}
# then: icons (section 2), and compare every file with ai/files/checksums.sha256, e.g.
Get-Content ai\files\checksums.sha256 | Where-Object { $_ -and -not $_.StartsWith("#") } | ForEach-Object {
  $h, $p = $_ -split "  ", 2
  if ((Get-FileHash -Algorithm SHA256 $p).Hash.ToLower() -ne $h) { "MISMATCH $p" }
}
```

(`Invoke-WebRequest -OutFile` writes the bytes unchanged; do not pipe downloads through text cmdlets.)
